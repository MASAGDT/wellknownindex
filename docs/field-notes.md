## Field note: Cloudflare blocks Python's default User-Agent

API calls from Python's urllib get HTTP 403 from Cloudflare; the same calls with a browser User-Agent succeed.

## Field note: Queued is not changed

A submitted order is staged or queued — not applied. Verify the receipt and check the outcome; never claim success from the request alone.
